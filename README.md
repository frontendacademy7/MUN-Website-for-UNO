README Introduction
🌍 Model United Nations (MUN) — UNO Website

A modern, responsive, and interactive Model United Nations (MUN) website designed for an UNO/MUN event. The website provides participants with essential event information, committee details, registration information, schedules, and other important resources in an attractive and easy-to-navigate interface.

🛠️ Technologies Used
HTML5 — Website structure
CSS3 — Styling, animations, and responsive design
JavaScript — Interactive functionality
✨ Features
🌐 Modern MUN/UNO design
📱 Responsive layout
🏛️ Committee information
📅 Event/schedule section
📝 Registration information
👥 Team/organizer section
📞 Contact section
🎨 Interactive UI and animations
⚡ Fast and lightweight frontend
🎯 Purpose

The website is designed to provide MUN delegates and participants with a professional online platform where they can easily find information about the event, committees, registration, schedules, and organizers.

Built with ❤️ using HTML, CSS & JavaScript.
